# Архітектура

Дві частини, один домен для користувача.

```
   браузер
      │
      ├── https://map.navernyborshchu.com   статика з /var/www/nb-map/current
      │        React SPA (CRA), Google Maps JS API
      │
      └── https://api.navernyborshchu.com   gunicorn → Django + DRF
               PostgreSQL, медіа на диску, JWT
```

Фронтенд і бекенд — окремі деплої з різними механізмами (див.
[deploy.md](deploy.md)), тому вони живуть в одному репозиторії, але не в одному
процесі: фронт ходить у бекенд по HTTP, як будь-який сторонній клієнт.

## Фронтенд (`frontend/`)

Create React App 5 + React 19. Без Redux: стан тримають контексти в
`src/context/`.

| Контекст | За що відповідає |
|---|---|
| `UserContext` | сесія, профіль, вхід через Google |
| `PlacesContext` | заклади |
| `BorschContext` | борщі, стани розвідки (`virgin` / `unverified` / `confirmed`) |
| `FavoritesContext` | обране (серверне, тільки для авторизованих) |
| `CommentsContext` | відгуки |
| `FiltersContext` | фільтри списку й мапи |

Ключові теки:

- `src/api/index.js` — єдина точка HTTP до бекенду. Тут же округлення координат
  до шести знаків і розбір помилок DRF по полях.
- `src/services/` — сесія і токени (`authSession`, `tokenStorage`,
  `googleAuth`) та робота з Google Places (`placesLookup`): пошук закладу,
  резолв тапу по мапі, пошук поруч.
- `src/components/QuestFlow/` — рушій «квесту» оцінювання: кроки
  scale/choice/text/number/photo/comment/signin/done, свій колір на крок,
  сегментний прогрес, реакція маскота.
- `src/page/AddBorschFlow/` — додавання нового борщу. Ланцюг записів
  place → borsch → review → photo тримає `progress`, щоб повтор після збою не
  створив другий заклад.
- `src/i18n/` — усі тексти, `uk` і `en`.
- `src/styles/`, `src/index.scss` — токени, теми (світла/темна), спільні
  змінні на кшталт `--nb-vh` і `--nb-topbar-h`.

Маршрути описані в `src/App.js`: `/` — мапа, `/list` — список, `/borsch/:id` —
борщ, `/add-borsch/*` — додавання, `/profile/*` — профіль. `/favorite` і
`/reviews` закриті `PrivateRoute`.

### Оцінки: контракт даних

В інтерфейсі користувач бачить пʼять словесних відповідей на кожне питання.
У базу йде **шкала 1–10** (2/4/6/8/10) — той самий контракт, що був до
редизайну, тому старі й нові відгуки складаються в одну статистику.

Шкала солі немонотонна: 2 — прісний, 10 — пересолений. Настрій маскота й
похвала обчислюються з обраної відповіді (`optionForValue()`), а не з числа.

## Бекенд (`backend/`)

Django 4.2 + DRF, застосунок один — `core`.

| Модель | Призначення |
|---|---|
| `Place` | заклад: назва, адреса, координати, місто, країна, тип |
| `PlaceType` | довідник типів закладів |
| `Borsch` | борщ у закладі: назва, мʼясо, ціна, вага, фото, агреговані оцінки |
| `Review` | відгук: шість оцінок + загальна, текст, автор або `temp_user_id` |
| `UserProfile` | профіль поверх `auth.User`: Google id, імʼя, аватар, локаль |
| `FavoriteBorsch` | обране користувача |

Первинні ключі — UUID, крім довідників.

**Агрегати.** `Borsch.overall_rating` та `rating_*` — це не поля, які пише
клієнт: вони перераховуються з відгуків (`core/ratings.py`, сигнали в
`core/signals.py`). Команда `manage.py recalculate_borsch_ratings` полагодить
розʼїхані значення (`--dry-run` покаже, що саме змінилося б).

**Авторизація.** Google Sign-In на фронті → `POST /api/auth/google/` з ID
token → сервер верифікує його через `google-auth` проти
`GOOGLE_OAUTH_CLIENT_IDS` і видає власну пару JWT (SimpleJWT, з ротацією і
блоклистом refresh-токенів). Пароля в проєкті немає взагалі.

**Анонімні відгуки.** До входу відгук привʼязується до `temp_user_id`
(пристрій), після входу — до користувача. Так працює гість, який оцінив борщ
і лише потім зареєструвався.

**Тротлінг** налаштований у `REST_FRAMEWORK['DEFAULT_THROTTLE_RATES']`
(`core/throttles.py`) — запис дорожчий за читання.

Повний перелік ендпоінтів — [api.md](api.md) і `backend/openapi.yaml`.

## Чому саме так

- **CRA, а не Vite/Next.** Проєкт починався на CRA, а міграція — це ризик без
  користувачевої вигоди. Одного разу її вже пробували зробити «тихо», і прод
  два тижні крутив іншу апку (див. [deploy.md](deploy.md)).
- **Свій i18n замість бібліотеки.** Двомовний словник на кількасот рядків не
  вартий залежності.
- **Медіа на диску, не в S3.** Кількасот фотографій. Коли їх стануть тисячі —
  буде привід.
